# SKConnect

**A Web-based Barangay Youth Information and Project Transparency Platform**

SKConnect is a centralized website for the Sangguniang Kabataan (SK) of Barangay Sta. Rita, Olongapo City. It helps the youth and the community find SK announcements and opportunities, and view completed SK projects together with their budget and expense details.

## Purpose

SK information is often scattered across social media posts, separate files, and other channels. SKConnect puts it in one accessible place and promotes transparency and accountability in how SK projects and funds are handled.

## Features

**For the youth and the public**
- Announcements and updates (events, activities, scholarships, training, and other opportunities)
- Completed SK projects with descriptions, photos, and completion dates
- Project budget and expenditure information
- Project documentation (accomplishment reports and outputs)

**For SK officials**
- Admin dashboard to create, edit, publish, and manage announcements and project records
- Project documentation management

## Out of Scope (Initial Version)

- Online application processing
- Application tracking
- Youth concern management

## Tech Stack

- HTML
- CSS
- JavaScript
- [Font Awesome](https://fontawesome.com/) (icons)

## Getting Started

1. Clone the repository
```
   git clone <repository-url>
```
2. Open the project folder in VS Code.
3. Run `index.html` with the **Live Server** extension, or open it directly in your browser.

## Target Users

- **Primary:** Youth of Barangay Sta. Rita, Olongapo City
- **Secondary:** SK Chairperson, SK Councilors, and authorized SK personnel
