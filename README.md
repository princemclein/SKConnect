# SKConnect

**SKConnect: A Web-based Barangay Youth Information and Project Transparency Platform**

SKConnect is a web-based information and transparency portal for the
Sangguniang Kabataan (SK) of Barangay Sta. Rita, Olongapo City. It provides a
centralized place where residents, particularly the youth, can access SK
announcements, youth opportunities, completed projects, project documentation,
and available budget and expenditure information.

## Website Purpose

The main purpose of SKConnect is to make information from the Sangguniang
Kabataan more accessible to the youth and the general community. The platform
organizes announcements about events, youth activities, scholarships, training
programs, and other opportunities in one location.

SKConnect also promotes transparency and accountability by presenting completed
SK projects together with descriptions, photographs, accomplishment reports,
and available verified financial information. An administrative dashboard
provides the planned interface for authorized SK officials to manage
announcements and maintain project records.

## Project Description

SKConnect is designed for one selected barangay and focuses on information
dissemination and project transparency. Public users can browse current and
previous announcements, learn about available youth opportunities, and explore
completed SK projects. Project pages may include completion dates, photographs,
accomplishment reports, project outputs, budget allocations, actual
expenditures, and expense breakdowns when verified information is available.

SK officials can use the administrative interface to organize announcement and
project information for public presentation. The initial version focuses on
publishing and presenting information rather than processing applications or
managing youth concerns.

## Features

### For the Youth and General Public

- **Announcements and Updates:** View events, agendas, youth activities,
  scholarships, training programs, and other opportunities.
- **Completed SK Projects:** Explore project descriptions, photographs,
  completion dates, and documented accomplishments.
- **Project Budget and Expenditure Information:** Review available and verified
  project allocations, actual expenses, and expense breakdowns.
- **Project Documentation:** Access available accomplishment reports, project
  outputs, and supporting documents.

### For SK Officials

- **Administrative Dashboard:** Manage the administrative sections for
  announcements and project records.
- **Announcement Management:** Create, edit, and organize announcement
  information through the admin interface.
- **Project Documentation Management:** Organize project descriptions,
  photographs, reports, and financial information for public presentation.

## Problem Addressed

SK announcements and project information may be scattered across social media
posts, separate files, and other communication channels. This can make it
difficult for residents to find important updates, review previous
announcements, and understand the accomplishments and use of funds associated
with SK projects.

SKConnect addresses these concerns by:

1. Centralizing announcements, events, and youth opportunities in one
   accessible website.
2. Providing a public section for completed projects, photographs, descriptions,
   and accomplishment documentation.
3. Organizing available and verified project budget and expenditure information
   for easier community review.

## Target Users

### Primary Users

**Youth of Barangay Sta. Rita, Olongapo City**

Young residents can use SKConnect to find announcements, upcoming events,
scholarships, training opportunities, youth programs, and information about
completed SK projects.

### Secondary Users

**Sangguniang Kabataan Officials of Barangay Sta. Rita, Olongapo City**

The SK Chairperson, SK Councilors, and other authorized SK personnel can use
the administrative interface to organize announcements, update youth activity
information, and document completed projects for public viewing.

## Initial Scope and Limitations

The initial version focuses on information dissemination and project
transparency for one barangay.

The following features are outside the initial scope:

- Online application processing
- Application tracking
- Comprehensive youth concern management

The current project is a frontend implementation using HTML, CSS, and
JavaScript. The admin forms currently demonstrate the interface, validation,
and image previews, but do not permanently save or publish records. Backend
authentication, database persistence, and a production publishing workflow may
be added in a future version.
